# امنا یار — نسخه 3.2

نسخه 3.2 امنا یار یک مرکز خدمات کاربردی است:

- **استعلام واقعی:** کاربر به سامانه رسمی مرجع هدایت می‌شود؛ نتیجه جعلی یا شبیه‌سازی‌شده تولید نمی‌شود.
- **اعتبارسنجی داخلی:** کد ملی، کارت بانکی و شبا با الگوریتم‌های ساختاری بررسی می‌شوند.
- **داشبورد جدید:** خدمات رسمی، ابزارهای رایگان، سوابق و طراحی موبایل‌محور.
- **محتوای جذب کاربر:** دسته‌بندی موضوعات محبوب برای توسعه صفحات آموزشی و شبکه‌های اجتماعی.

## خدمات رسمی فعلی

- بیمه مرکزی / سنهاب
- استعلام چک صیادی بانک مرکزی
- رهگیری مرسوله شرکت ملی پست
- پنجره ملی خدمات دولت هوشمند
- خدمات الکترونیک انتظامی
- ثبت نشانی
- شرکت ملی پست
- درگاه ملی ایران

## نکته امنیتی

هیچ نتیجه‌ای درباره مالکیت، موجودی، سوابق یا وضعیت فعال یک حساب/شماره صرفاً از روی تعداد ارقام ادعا نمی‌شود. هرجا دسترسی رسمی لازم باشد، کاربر به مرجع رسمی هدایت می‌شود.


## نسخه 3.3 — پنل منابع انسانی و گزارش سازمانی

- نقش جدید `hr` برای مدیر منابع انسانی.
- ساخت سازمان از پنل مالک و اتصال مدیر HR با ایمیل حساب کاربری.
- داشبورد سازمانی با اطلاعات فروشگاه، پرسنل و حضور و غیاب.
- آپلود Excel/CSV تا سقف ۸MB با تشخیص ستون‌های فارسی/انگلیسی.
- خروجی Excel چندبرگه و CSV.
- ستون‌های اصلی: کد فروشگاه، نام فروشگاه، آدرس، کد پستی، سوپروایزر، کد پرسنلی، نام، نام خانوادگی، اضافه‌کار، ساعت مجاز، درصد حضور و مازاد حضور.
- فیلتر دوره و جستجوی نام/کد پرسنلی/فروشگاه.
- هیچ داده‌ای از مالکیت یا اطلاعات بانکی کاربران از طریق این پنل استنتاج نمی‌شود؛ اطلاعات HR فقط از فایل/داده‌ای که سازمان وارد می‌کند نمایش داده می‌شود.

### قالب پیشنهادی فایل HR

می‌توانید ستون‌ها را با نام‌های فارسی زیر یا معادل انگلیسی آن‌ها وارد کنید: `کد فروشگاه`، `نام فروشگاه`، `آدرس فروشگاه`، `کد پستی فروشگاه`، `سوپروایزر فروشگاه`، `کد پرسنلی`، `نام پرسنل`، `نام خانوادگی پرسنل`، `اضافه کار پرسنل`، `ساعت مجاز پرسنل`، `درصد حضور پرسنل`، `مازاد حضور پرسنل`، `دوره`.


نسخه ۳.۶.۴: ترتیب مقداردهی ابزارهای آپلود و پردازش رسانه اصلاح شد تا سرویس هنگام شروع با خطای mediaUpload قبل از initialization متوقف نشود.


نسخه 3.6.6: فشرده‌سازی تصویر با Sharp، PDF با Ghostscript، ویدئو با FFmpeg، و ترجمه فارسی↔انگلیسی اضافه/اصلاح شد.

## پنل واقعی مالک — نسخه 3.9.0

مسیر پنل مالک: `/owner`

این پنل فقط برای کاربری با `role=owner` قابل دسترسی است و شامل نمای کلی سامانه، مدیریت کاربران، بررسی‌ها، سازمان‌ها، رویدادهای مدیریتی و سلامت سرویس است.

- تغییر نقش کاربر: کاربر / مدیر HR / مالک
- فعال یا غیرفعال کردن حساب
- تأیید یا لغو تأیید حساب
- ثبت رویدادهای مدیریتی در دیتابیس
- نمایش آمار کاربران، بررسی‌ها، گفتگوها و سازمان‌ها
- مشاهده وضعیت API و دیتابیس
- خروجی Excel

رمز مالک فقط از `OWNER_EMAIL` و `OWNER_PASSWORD` در Environment Variables ساخته/به‌روزرسانی می‌شود و نباید داخل کد قرار گیرد.
