# امنا یار — نسخه 1.2 آزمایشی

این نسخه برای تست روی سرویس جداگانه `amnayar-modern` آماده شده و به نسخه فعلی `amnayar.ir` دست نمی‌زند.

## تغییرات نسخه 1.2
- فراموشی رمز و بازیابی با ایمیل از رابط کاربری و API حذف شد.
- خرید اعتبار، بسته‌ها و پرداخت دستی از رابط عمومی حذف شد.
- استعلام کد ملی، کارت و شبا رایگان و بدون محدودیت اعتباری شد.
- کسر اعتبار از استعلام‌ها حذف شد.
- دستیار **AmnaYar AI** به سایت اضافه شد.
- گفت‌وگوهای AI در PostgreSQL ذخیره می‌شوند.
- امکان ارسال تصویر به AI در پنل هوش مصنوعی وجود دارد.
- کلید OpenAI فقط سمت سرور استفاده می‌شود و نباید در مرورگر قرار بگیرد.

## متغیرهای Render
- `DATABASE_URL`
- `JWT_SECRET`
- `OPENAI_API_KEY`
- `OPENAI_MODEL` (پیشنهاد: `gpt-5.6-luna`)
- `OWNER_EMAIL`
- `OWNER_PASSWORD`

## نکته مهم
تا وقتی `OPENAI_API_KEY` روی Render تنظیم نشده باشد، صفحه هوش مصنوعی باز می‌شود اما پاسخ AI در دسترس نخواهد بود.

استعلام‌های کد ملی، کارت و شبا به‌صورت ساختاری انجام می‌شوند و این نسخه ادعای مالکیت حساب یا فعال بودن واقعی حساب بانکی را ندارد.
