# امنا یار — نسخه 3.6.3

این نسخه ابزارهای رایگان کم‌حجم‌کردن تصویر، PDF و ویدئو را اضافه می‌کند.

- تصویر: تبدیل به JPEG کم‌حجم با کیفیت قابل تنظیم
- PDF: فشرده‌سازی با Ghostscript در سه سطح
- ویدئو: فشرده‌سازی MP4 با H.264/AAC در سه سطح
- سقف آپلود رسانه: 100MB
- فایل‌ها برای پردازش موقت هستند و پس از پردازش حذف می‌شوند.

برای استقرار Render، سرویس باید در build از Ghostscript و FFmpeg استفاده کند؛ این نسخه در render.yaml نصب آن‌ها را در زمان build انجام می‌دهد.
