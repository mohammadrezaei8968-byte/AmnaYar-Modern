# امنا یار Modern — نسخه 2.6 Free Local AI

این نسخه برای حالت تبلیغاتی طراحی شده است. AI متنی با WebLLM و مدل Qwen2.5-0.5B داخل مرورگر کاربر اجرا می‌شود؛ بنابراین برای چت متنی به OPENAI_API_KEY و اعتبار API نیاز ندارد. WebGPU موردنیاز است و مدل حدود 945MB برای بار اول دانلود و در مرورگر cache می‌شود.

نکته: این نسخه عمداً تحلیل تصویر و تولید تصویر OpenAI را برای حذف وابستگی به API انجام نمی‌دهد. فایل‌های متنی/کد می‌توانند در مرورگر خوانده و به مدل داده شوند.

برای کاربران، محدودیت پیام یا شمارنده‌ای نمایش داده نمی‌شود. هزینه inference متنی از سرور AmnaYar دریافت نمی‌شود چون مدل روی دستگاه کاربر اجرا می‌شود.


### نسخه 2.7
اگر WebGPU/GPU در مرورگر در دسترس نباشد، هوش مصنوعی به‌صورت خودکار با Transformers.js و WASM روی CPU اجرا می‌شود.
