# امنا یار — نسخه 3.0 خدمات استعلام رایگان

در این نسخه قابلیت هوش مصنوعی حذف شده و تمرکز سامانه روی استعلام‌ها و ابزارهای صحت‌سنجی رایگان است.

## خدمات داخلی
- کد ملی
- کارت بانکی و تشخیص بانک از پیش‌شماره
- شبا و تشخیص بانک/کد بانک/شماره حساب
- شناسه ملی شرکت
- کد پستی
- شماره موبایل
- کد رهگیری پستی
- VIN خودرو
- قالب پلاک خودرو
- شناسه صیادی
- قالب شماره حساب

ابزارهای ساختاری بدون API پولی کار می‌کنند. برای خدماتی که نیازمند احراز هویت یا دسترسی به پایگاه رسمی هستند، لینک مرجع رسمی نمایش داده می‌شود و نتیجه‌ای جعل نمی‌شود.
