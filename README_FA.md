# امنا یار — نسخه 3.2

نسخه 3.2 امنا یار یک مرکز خدمات کاربردی است:

- **استعلام واقعی:** کاربر به سامانه رسمی مرجع هدایت می‌شود؛ نتیجه جعلی یا شبیه‌سازی‌شده تولید نمی‌شود.
- **اعتبارسنجی داخلی:** کد ملی، کارت بانکی و شبا با الگوریتم‌های ساختاری بررسی می‌شوند.
- **داشبورد جدید:** خدمات رسمی، ابزارهای رایگان، سوابق و طراحی موبایل‌محور.
- **محتوای جذب کاربر:** دسته‌بندی موضوعات محبوب برای توسعه صفحات آموزشی و شبکه‌های اجتماعی.

## خدمات رسمی فعلی

- بیمه مرکزی / سنهاب
- استعلام چک صیادی بانک مرکزی
- رهگیری مرسوله شرکت ملی پست
- پنجره ملی خدمات دولت هوشمند
- خدمات الکترونیک انتظامی
- ثبت نشانی
- شرکت ملی پست
- درگاه ملی ایران

## نکته امنیتی

هیچ نتیجه‌ای درباره مالکیت، موجودی، سوابق یا وضعیت فعال یک حساب/شماره صرفاً از روی تعداد ارقام ادعا نمی‌شود. هرجا دسترسی رسمی لازم باشد، کاربر به مرجع رسمی هدایت می‌شود.
