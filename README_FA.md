# امنا یار — نسخه مدرن Full-Stack

این پروژه یک نمونه کامل Node.js + Express + PostgreSQL برای امنا یار است.

## امکانات
- ثبت‌نام با ایمیل یکتا و نام کاربری یکتا
- ۲ اعتبار رایگان هنگام ثبت‌نام
- ورود و خروج
- فراموشی نام کاربری با ایمیل
- بازیابی رمز با لینک یک‌بارمصرف و زمان‌دار
- داشبورد کاربر
- استعلام کد ملی، کارت بانکی و شبا
- هر استعلام = یک اعتبار
- بسته‌های خرید اعتبار
- سفارش خرید و تأیید دستی توسط مالک
- پنل مالک جداگانه
- گزارش Excel از کاربران، سفارش‌ها و استعلام‌ها
- لوگوی دقیق رسمی در فایل `public/assets/logo-amnayar.png`
- تصاویر آموزشی غیرواقعی برای کد ملی، کارت و شبا

## پرداخت
شماره کارت مقصد **عمداً داخل کد عمومی نوشته نشده**. آن را فقط در متغیر محیطی `PAYMENT_CARD` روی سرور قرار دهید. کاربر سفارش را ثبت می‌کند، مبلغ را انتقال می‌دهد و مالک پس از بررسی رسید/تراکنش، سفارش را تأیید می‌کند. سیستم نباید ادعا کند انتقال بانکی خودکار تأیید شده است مگر اینکه به درگاه/بانک متصل شود.

## راه‌اندازی
1. PostgreSQL بسازید.
2. `.env.example` را به `.env` تبدیل کنید.
3. `DATABASE_URL`, `JWT_SECRET`, `OWNER_EMAIL`, `OWNER_PASSWORD`, SMTP و `PAYMENT_CARD` را پر کنید.
4. اجرا: `npm install` سپس `npm start`.
5. روی Render یا سرور Node اجرا کنید و دامنه `amnayar.ir` را به آن وصل کنید.

## امنیت
رمزها هش می‌شوند و رمز قبلی از طریق ایمیل ارسال نمی‌شود. بازیابی با توکن یک‌بارمصرف و محدودیت زمانی انجام می‌شود. برای تولید واقعی، HTTPS، محدودیت نرخ درخواست، لاگ امنیتی و سرویس SMTP واقعی را فعال کنید.


## وضعیت نسخه 1.1
این نسخه قبل از انتشار، چند ایراد مهم نسخه اولیه را اصلاح می‌کند:
- تراکنش‌های کسر اعتبار و تأیید سفارش روی یک اتصال PostgreSQL انجام می‌شوند.
- قفل ردیف سفارش/اعتبار داخل تراکنش انجام می‌شود.
- برای ورود، ثبت‌نام، بازیابی و استعلام محدودیت درخواست اضافه شده است.
- مسیر fallback با Express 5 سازگار شده است.
- بعد از ثبت سفارش، شماره کارت مقصد از تنظیمات سرور به کاربر نمایش داده می‌شود.
